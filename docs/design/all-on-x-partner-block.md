# Approved All-on-X partner-benefits direction — 2026-10-13

Ramon selected the compact two-column reference during the design review and
explicitly requested implementation using the original photography, not generated
replacement images.

- Left: the six existing `assets/all-on-x/partner-*.webp` photos, in order, in a
  two-column / three-row grid, followed by the existing three-part statement.
- Right: existing eyebrow, serif heading, introduction, and four numbered benefits.
- Both desktop columns share one grid row and therefore equal height. The content
  determines that height; images must not impose intrinsic sizing on the grid.
- Photography uses proportional `object-fit: cover`, never stretched or squashed.
  Individual focal positions retain the restoration / machine / people in frame.
- A single dark proof strip with the four existing icons spans both columns below.
- Retain Cormorant Garamond, Montserrat and Open Sans, warm cream, charcoal, coral
  accents and the existing outline icon family. Open separated text rows, not large
  rounded cards or floating decoration. No additional CTA.
- Preserve all Hungarian and German copy and every original photo and icon.
- On small screens, show the complete text then the complete photo grid, followed
  by the proof strip; do not force two narrow equal-height columns on mobile.

The shared style owner is `assets/all-on-x/partner-reasons.css`, loaded only by the
Hungarian and German All-on-X pages. No generated design image is used by the site.
